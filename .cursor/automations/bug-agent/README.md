# Bug agent operational pack

Single combined Slack bug triage + resolution agent for this repository.

| File | Role |
|------|------|
| `OPERATIONS.md` | Authoritative run instructions (Automations editor prompts must read this) |

Configuration and feature maps live outside this directory at `.cursor/bug-automation/` so pack updates do not overwrite user-owned settings.

This is **not** the Benny two-job pack. Do not add a separate triage automation beside this agent.
